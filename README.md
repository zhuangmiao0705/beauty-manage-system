# 聚尚木子门店管理系统

本项目是一个本地离线运行的美容院管理应用，使用 Vue 3 + Tauri 2 + SQLite。

## 已实现

- 会员档案、新增会员、会员等级与余额管理
- 会员充值、消费和完整资金流水
- 员工服务记录、服务金额与提成计算
- 员工档案、提成比例、在职/停用状态管理
- 店长与员工两级登录权限、账号启停与密码重置
- Argon2 密码哈希、个人密码修改与店长重置
- 今日、近 30 天、季度、年度营收统计
- 营收曲线、员工业绩排行和 CSV 报表导出
- SQLite WAL/FULL 安全配置
- 数据库手动备份、最近备份恢复
- Tauri Updater 更新入口
- 浏览器演示模式使用 localStorage，正式应用自动切换 SQLite

## 初始登录

- 店长账号：`admin`
- 初始密码：`123456`
- 首次登录可直接使用系统，之后可在“个人账号”中修改密码

店长可使用“员工与账号”模块创建员工登录账号。员工只能处理日常会员业务、登记并查看本人服务记录及修改本人密码，无法进入营收、员工账号和系统设置。

## 本地开发

```bash
npm install
npm run dev
```

桌面应用需要先安装 Rust：

```bash
rustup toolchain install stable
npm run tauri dev
```

## 构建安装包

```bash
npm run tauri build
```

应用标识固定为 `com.jumeimuzi.salon`，不要随意修改，否则新版可能无法自动找到旧版数据目录。
